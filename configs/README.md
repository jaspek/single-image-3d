# Evaluation subsets

Generated by `python scripts/make_subsets.py` once the data is downloaded:

- `subset_nyu.txt`: 50 frame ids from the official NYU Depth v2 test split (seed 0).
- `subset_pix3d.txt`: 50 Pix3D image ids, unoccluded and untruncated, spread over the
  categories (seed 0).

- `dev_pix3d.txt`: 45 other Pix3D images (5 per category, seed 1, none of them in the
  subset). Thresholds of a method are chosen on these, never on the subset.
- `dev_large_pix3d.txt`, `holdout_pix3d.txt`: two more lists of 639 Pix3D images each
  (unoccluded, untruncated, up to 90 per category, seed 7), disjoint from each other and
  from the subset. The symmetry method chose its rules on the first and was checked once
  on the second; 45 images turned out to be too few to choose on.

Format: one id per line, first token is the id, anything after `#` is a comment. All
methods run on these ids and nothing else is compared.
