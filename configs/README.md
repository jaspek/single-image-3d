# Evaluation subsets

Generated by `python scripts/make_subsets.py` once the data is downloaded:

- `subset_nyu.txt`: 50 frame ids from the official NYU Depth v2 test split (seed 0).
- `subset_pix3d.txt`: 50 Pix3D image ids, unoccluded and untruncated, spread over the
  categories (seed 0).

Format: one id per line, first token is the id, anything after `#` is a comment. All
methods run on these ids and nothing else is compared.
