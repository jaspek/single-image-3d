# Results

- `depth_summary.md`, `shape_summary.md`: one row per method, mean over the subset.
  Regenerated by `scripts/eval_depth.py` and `scripts/eval_shape.py` from the CSV files, so
  never edit them by hand.
- `depth/<method>.csv`, `shape/<method>.csv`: per-sample metrics with the evaluation
  settings used (`align`, `space`, `gt_frame`, `tau`).

Commit the CSVs and the summaries. Prediction files under `outputs/` are not committed.

Depth metrics (NYU protocol): AbsRel, SqRel, RMSE, RMSE log, log10, delta < 1.25 / 1.25^2 /
1.25^3; optional normal errors (mean / median angle, % below 11.25, 22.5, 30 degrees).
Shape metrics (in units of the bounding-box diagonal of the ground-truth model): accuracy
(pred -> gt), completeness (gt -> pred), Chamfer (sum of both), F-score at tau. The `align`
column says how the prediction was aligned first: `icp` = similarity transform with rotation
search, `camera` = one scale factor about the camera centre (prediction in the camera
frame), `none`. Numbers with different `align` are not directly comparable. The `n` column
of the summary counts the images that have a prediction.

- `symmetry_status.csv`: one row per image for the symmetry method (status, source of the
  plane, reason of a refusal, detected plane, view angle), including the images where no
  plane was accepted.
- `symmetry_plane.csv`: the detected plane against the symmetry planes of the CAD model.
- `shape/symmetry_hull.csv` is the result of the symmetry method (plane from the straight
  edges, silhouette intersection); `shape/symmetry.csv` are its matched points.
- Variants of the symmetry method, for comparison only: `symmetry_features*` takes the plane
  from mirrored feature pairs, `symmetry_twocones_hull` uses the plane from the edges with
  one mirrored camera only, `symmetry_trueplane_hull` takes the plane from the CAD model
  and the annotated pose.
