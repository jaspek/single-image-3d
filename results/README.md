# Results

- `depth_summary.md`, `shape_summary.md`: one row per method, mean over the subset.
  Regenerated by `scripts/eval_depth.py` and `scripts/eval_shape.py` from the CSV files, so
  never edit them by hand.
- `depth/<method>.csv`, `shape/<method>.csv`: per-sample metrics with the evaluation
  settings used (`align`, `space`, `gt_frame`, `tau`).

Commit the CSVs and the summaries. Prediction files under `outputs/` are not committed.

Depth metrics (NYU protocol): AbsRel, SqRel, RMSE, RMSE log, log10, delta < 1.25 / 1.25^2 /
1.25^3; optional normal errors (mean / median angle, % below 11.25, 22.5, 30 degrees).
Shape metrics (unit object size): accuracy (pred -> gt), completeness (gt -> pred), Chamfer
(sum of both), F-score at tau.
